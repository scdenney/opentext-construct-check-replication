# Sources of the public datasets redistributed here

Each file below is a harmonized copy of data deposited by the authors named. The copy has one row per answer; columns are renamed to the schema in `docs/codebook.md`; text is trimmed and re-encoded as UTF-8; rows the original authors exclude are flagged in `exclude`, not dropped; one e-mail address that a respondent typed into an answer (`musgrave2026_sanctionswtp`) is replaced by a note. The scripts that made each copy are in `analysis/revision/harmonize/` of the main dataset, and `docs/data_sources.csv` names the source files.
